## 一、两条线必须先分清：养生（非医疗） vs 医疗（诊疗）

这两者的法律边界是**硬墙**，不是梯度。

| | 医疗机构 | 非诊疗类养生服务机构 |
|---|---|---|
| 依据 | 《中医药法》《医疗机构管理条例》 | 《中医养生保健服务规范（试行）》 |
| 能否针刺 | ✅ 可（需执业医师） | ❌ 绝对禁止 |
| 能否开方 | ✅ 可 | ❌ 绝对禁止 |
| 能否宣传治疗 | 需《医疗广告审查证明》 | ❌ 绝对禁止 |
| 能否拔罐/推拿/艾灸 | ✅ 可 | ✅ 可（非侵入） |
| 能否口服中药饮片 | ✅ 可（处方） | ❌ 仅限食药/保健食品清单内 |

### 非诊疗类服务禁止清单（规范第五条，逐条落地）

| # | 禁止行为 | 校验方式 |
|---|---|---|
| 1 | 针刺、瘢痕灸、发泡灸、牵引、扳法、中医微创类技术、中药灌洗肠 | `FORBIDDEN_PROJECTS` 扫「关联项目」字段 |
| 2 | 开具药品处方 | `FORBIDDEN_TERMS` 含「开方」「处方」「医嘱」 |
| 3 | 口服非《既是食品又是药品的物品名单》《可用于保健食品的物品清单》的中药饮片 | `PRESCRIPTION_HERBS` + `食药清单.json` 逐味核验 |
| 4 | 开展医疗气功 | 人工审核 + 术语审查 |
| 5 | 其他诊疗活动 | 校验器人工复核 |

> 灸法要区分：**温和灸/悬灸/温热灸（热刺激，无创）合规**；**瘢痕灸/发泡灸（造成创面）禁止**。
> 温热类服务的描述要避免"祛湿驱寒""活血化瘀"等医疗用语（见第三节）。

## 二、疗效与功效表述红线（《广告法》第十七、十八条）

### 绝对禁止的表述

| 类别 | 禁用词示例 | 校验器词表 |
|---|---|---|
| 疾病治疗类 | 治疗/根治/治愈/防治高血压糖尿病、专治颈椎病、治肿瘤、防癌抗癌 | `FORBIDDEN_TERMS` |
| 医疗行为类 | 消炎杀菌、排毒祛湿、修复受损细胞、调节内分泌 | `FORBIDDEN_TERMS` |
| 易混淆医疗概念 | 药食同源（用于普通食品推广时）、中医调理（非医疗或药品广告）、穴位治疗 | `FORBIDDEN_TERMS` |
| 常见但违规的中医用语 | 经络疏通、祛湿驱寒、活血化瘀、滋阴补阳、古法治病 | `FORBIDDEN_TERMS` + `EFFICACY_CLAIMS` |
| 绝对化用语 | 国家级、最高级、最佳、顶级、极品、第一品牌、祖传秘方、唯一 | 人工审核 |
| 功效断言保证 | 无任何副作用、包好、保证见效、一次见效 | `FORBIDDEN_TERMS` |
| 专家背书 | 使用专家、医师、药师、患者名义或形象作推荐证明 | 人工审核 |

### 可用的替换词表

| 想表达 | ❌ 不能说 | ✅ 可以说 |
|---|---|---|
| 温热类服务改善怕冷 | 祛湿驱寒、散寒止痛 | 温热放松、暖养体感、节气时令调养 |
| 推拿缓解酸胀 | 治疗颈椎病、舒筋活络治疼痛 | 日常舒缓、久坐后放松、运动后肌肉放松 |
| 体质辨识 | 诊断亚健康、辨证论治 | 体质倾向评估、养生建议 |
| 睡眠调理 | 治疗失眠、改善重度失眠 | 作息与睡眠节律建议、安神助眠食养 |
| 经络 | 疏通经络（治疗义） | 穴位按揉、体表区位介绍 |

> 原则：**只说"做什么"和"什么体感"，不说"治什么病"和"效果多好"。**

## 三、互联网发布的特殊限制（《互联网广告管理办法》第八条 + 《广告法》第十九条）

这是养生赛道最容易踩、也最少人注意的一条。

> **原文**：「禁止以介绍健康、养生知识等形式，变相发布医疗、药品、医疗器械、保健食品、特殊医学用途配方食品广告。介绍健康、养生知识的，**不得在同一页面或者同时出现**相关医疗、药品、医疗器械、保健食品、特殊医学用途配方食品的**商品经营者或者服务提供者地址、联系方式、购物链接**等内容。」

### 实际后果

| 内容形态 | 是否合规 |
|---|---|
| 公众号文章讲失眠食疗 + 文末留微信号 | ❌ 违规 |
| 视频号讲养生 + 同屏挂商品链接 | ❌ 违规 |
| 养生文章 + 文末写"更多案例见评论区" | ✅ 合规 |
| 独立的**服务介绍页**（列项目与价格） | ✅ 合规（不与科普内容同页混排） |
| 养生科普页 + 文末放**非交易性质**的公众号名片（无链接无购买入口） | ⚠️ 灰色，视是否构成变相发布 |

### 结构性解法：科普与转化物理分离

```
科普内容（公众号 / 视频号 / 小红书）
    └── 纯知识，无联系方式、无购买链接、无"加我咨询"
              ↓
私域沉淀（微信群 / 知识星球）
    └── 群内才是转化场景，但群内内容要按"服务介绍"而非"科普"定性
              ↓
线下交付（已停办，不再是路径）
```

## 四、命理内容的特殊风险

「斗数运气·生辰调养」这类命理内容与中医养生绑定发布，有独立风险：

| 风险点 | 说明 | 处置 |
|---|---|---|
| 迷信导向 | 命理内容若宣称能预测疾病、寿命、财运 | 严格禁止「预测」「必」「定能」类表述 |
| 与疗效混同 | 把斗数结论说成医学诊断 | 必须区分「养生参考」与「医学诊断」 |
| 数据采集 | 收集生辰八字 = 个人信息，且属敏感推断 | 需明示用途；不做自动留存 |
| 平台规则 | 小红书/抖音对封建迷信内容限流严重 | 斗数内容不作为主账号主线 |

### 双链结构

| 链路 | 定位 | 内容 | 变现 |
|---|---|---|---|
| **中医养生链**（主） | 专业、可医疗背书 | 体质、辨证、食疗、节气、外治 | 会员订阅 + 咨询 |
| **斗数调养**（辅） | 文化体验、情绪价值 | 五运六气、起居建议、体质倾向 | 知识星球订阅 |

**关键**：斗数链路只做"起居节律建议、体质倾向参考"，**不与疗效承诺同框**。
生辰调养结果不得作为"你应该来治XX病"的依据。

## 五、发布前自检清单（每条文案必过）

```
[ ] 是否出现疾病治疗功能表述？          → 有 → 删除
[ ] 是否出现禁用医疗用语？              → 有 → 替换
[ ] 是否含绝对化用语或功效保证？        → 有 → 删除
[ ] 是否使用专家/医师/患者形象背书？    → 有 → 删除
[ ] 科普页面是否含联系方式/购买链接？   → 有 → 分离到私域或线下
[ ] 食疗方中每味药材是否在食药/保健食品清单内？ → 不确定 → 删方或改为一般性饮食建议
[ ] 服务项目是否含侵入性技术（针灸/埋线/发泡灸）？ → 有 → 移至医疗机构通道
[ ] 是否把斗数结论表述为诊断或预测？    → 有 → 改写为参考建议
[ ] 是否暗示"本品/本项目为健康所必需"？ → 有 → 删除
[ ] 是否含特定人群限定（孕产/术后/婴幼儿/康复期）？ → 有 → 改为通用表述
```

## 附：方法论来源与本赛道差异

本项目的「一人公司生存地图」结构借鉴自公开分享的一人公司内容方法论。
其可借鉴的做法：

| 做法 | 能否照搬 | 说明 |
|---|---|---|
| 早报卡片 + 选题引擎 | ✅ 可借鉴 | 骨架通用 |
| 内容分发给多平台 | ✅ 可借鉴 | 需按平台规则调整形式 |
| 私域群每日早报 | ✅ 可行 | 群内非"科普页" |
| 会员卡 / 直播课 | ✅ 可行 | 群内按"服务介绍"定性 |
| 早报带引导话术 + 引导加微信 | ❌ 不可照搬 | 养生科普不得带联系方式 |
| 公众号长文讲真实数据 | ⚠️ 可讲，但须去医疗化、去疗效化 | — |
| 视频号讲养生 + 挂链接 | ❌ 不可照搬 | 不得同屏出现购物链接 |
| 免费工具（体质自测）引流 | ⚠️ 可行，但结果页不得带购买入口与联系方式 | 由校验器强制 |
